## 📲 CONNECT WHATSAPP

### QR CODE SCAN

1. Install the bot on your VPS.
2. Run `npm install`.
3. Run `npm start`.
4. Wait for the QR code in your terminal.
5. Open WhatsApp on your phone.
6. Go to Linked Devices.
7. Select Link a Device.
8. Scan the QR code.

**Important:** Never share your QR code or session files with anyone.
