1. Install the bot on your VPS.
2. Install dependencies using "npm install".
3. Start the bot using "npm start".
4. Wait for the QR code in your terminal.
5. Open WhatsApp on your phone.
6. Select Linked Devices.
7. Tap Link a Device.
8. Scan the QR code.

pm2 save
